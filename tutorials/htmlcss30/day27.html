Day 27 条件分岐と繰り返し

🎯 今日のゴール Pythonの if と for を、正しいインデントで書ける。

score = 75
if score >= 80:
    print("よくできました!")
elif score >= 60:
    print("合格です")
else:
    print("再チャレンジ!")

for i in range(1, 6):
    print(i, "回目のこんにちは")

Pythonは波かっこ {} の代わりに「インデント(字下げ)」でブロックを表します。行末の : とインデント(半角スペース4つ)のセットを覚えましょう。range(1, 6) は1から5まで(6は含まない)です。

✍️ 今日の練習

1から100までの合計を for と range で計算してみましょう。JavaScriptのDay 20と同じ問題を、Pythonで解く形です。
