Day 24 演習:ミニアプリ

🎯 今日のゴール HTML・CSS・JavaScriptを組み合わせて、動くページを完成させる。

「おみくじアプリ」を作りましょう。ボタンを押すと「大吉」「中吉」「小吉」のどれかがランダムに表示されるページです。Day 23 のHTMLを流用して、scriptだけ次のように変えます。

const results = ["大吉", "中吉", "小吉"];

document.getElementById("btn").addEventListener("click", function () {
  const i = Math.floor(Math.random() * results.length);
  document.getElementById("message").textContent = results[i];
});

Math.random() は0以上1未満の乱数、Math.floor は小数点以下の切り捨てです。組み合わせると「0〜2のランダムな整数」が作れて、配列から1つを選べます。

✍️ 今日の練習

結果の種類を増やしたり、CSSで結果の文字を大きく目立たせたりして、自分らしいおみくじに仕上げましょう。
