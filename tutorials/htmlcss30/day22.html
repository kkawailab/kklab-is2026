Day 22 配列とオブジェクト

🎯 今日のゴール 配列とオブジェクトで、複数のデータをまとめて扱える。

const fruits = ["りんご", "みかん", "ぶどう"];
console.log(fruits[0]);        // りんご(0番から数える)
console.log(fruits.length);    // 3

const student = { name: "名城 太郎", grade: 1 };
console.log(student.name);     // 名城 太郎

配列は順番のあるデータの集まりで、先頭を0番として数えます。オブジェクトは名前(キー)で値を取り出すデータの集まりです。

✍️ 今日の練習

好きな食べ物の配列を作り、for (const f of fruits) { ... } の形のループで全部表示してみましょう。
