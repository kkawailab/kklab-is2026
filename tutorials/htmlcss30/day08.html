Day 8 フォーム

🎯 今日のゴール input や button を使って、入力欄のあるページを作れる。

<form>
  <label for="name">名前</label>
  <input type="text" id="name" placeholder="例: 名城 太郎">

  <label for="color">好きな色</label>
  <input type="color" id="color">

  <button type="button">送信(まだ動きません)</button>
</form>

<input> は type を変えると、テキスト・色・日付などいろいろな入力欄になります。<label> は入力欄の説明で、for と id を同じ値にして対応づけます。

💡 ボタンを押したときの処理を作るのはJavaScriptの仕事です(第3部で学びます)。ここでは「入力欄を並べられる」ことがゴールです。

✍️ 今日の練習

type="date" や type="range" など、type の値をいろいろ変えて表示がどう変わるか確かめましょう。
