Day 19 条件分岐

🎯 今日のゴール if・else if・else で、条件によって処理を変えられる。

const score = 75;

if (score >= 80) {
  console.log("よくできました!");
} else if (score >= 60) {
  console.log("合格です");
} else {
  console.log("再チャレンジ!");
}

比較には >=(以上)、<=(以下)、===(等しい)、!==(等しくない)を使います。「等しい」は = を3つ重ねる点に注意しましょう(= 1つは代入の意味です)。

✍️ 今日の練習

score の値を変えて実行し、3パターンすべてのメッセージが表示されることを確認しましょう。
