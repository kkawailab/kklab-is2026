Day 9 CSSとは

🎯 今日のゴール CSSの3つの書き方を知り、style タグでページに色を付けられる。

CSSはページの「見た目」を決める言語です。書き方は3つあります。①タグに直接書く(インライン)、②head内の <style> タグに書く、③外部CSSファイルに書く。この教材では②を使い、仕組みに慣れたら③に進むのがおすすめです。

<head>
  <style>
    p {
      color: blue;
    }
  </style>
</head>
<body>
  <p>この段落は青色になります。</p>
</body>

「セレクタ { プロパティ: 値; }」がCSSの基本形です。この例は「すべての p 要素の文字色(color)を青(blue)にする」という意味になります。
