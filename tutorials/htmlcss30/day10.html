Day 10 セレクタ

🎯 今日のゴール 要素・クラス・IDの3種類のセレクタを使い分けられる。

<style>
  p { color: gray; }          /* すべての p 要素 */
  .important { color: red; }  /* class="important" の要素 */
  #title { color: green; }    /* id="title" の要素(1つだけ) */
</style>

<h1 id="title">セレクタの練習</h1>
<p>ふつうの段落</p>
<p class="important">大事な段落</p>

クラス(.名前)は同じ名前を何度でも使えますが、ID(#名前)はページ内で1つだけです。迷ったらクラスを使いましょう。

✍️ 今日の練習

3つ以上の段落を作り、一部の段落だけ class を付けて色を変えてみましょう。

模範解答を見る 
<style>
  .important { color: red; }
</style>

<p>ふつうの段落です。</p>
<p class="important">この段落は大事なので赤色です。</p>
<p>これもふつうの段落です。</p>
<p class="important">締め切りは金曜日!ここも赤色です。</p>

同じ class を複数の要素に付けられること、class のない段落には適用されないことが確認できれば正解です。
