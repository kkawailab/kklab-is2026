Day 18 変数とデータ型

🎯 今日のゴール let と const を使い分けて、値を保存・計算できる。

const name = "名城 太郎";   // あとで変えない値
let age = 18;               // あとで変わる値

console.log(name + "さんは" + age + "歳です");
age = age + 1;
console.log("来年は" + age + "歳です");

const は再代入できない変数、let は再代入できる変数です。基本は const を使い、あとで値を変える必要があるときだけ let を使います。文字列は " で囲み、+ でつなげられます。
